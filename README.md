# آهن‌پیچ — سایت تک‌صفحه‌ای پله‌های آهنی پیچ‌دار

## 📁 ساختار فایل‌ها

```
spiral-stairs/
├── index.html              ← فایل اصلی HTML (محتوای همه بخش‌ها)
├── styles.css              ← استایل‌های CSS
├── scripts.js              ← اسکریپت‌های JS (شامل Lenis + GSAP + barba init)
├── README.md               ← همین فایل
├── vendor/                 ← کتابخانه‌های JS (آفلاین)
│   ├── lenis.min.js        ← اسکرول نرم
│   ├── barba.umd.min.js    ← انتقال صفحات
│   ├── gsap.min.js         ← انیمیشن
│   └── ScrollTrigger.min.js ← پلاگین GSAP
└── assets/                 ← پوشه عکس‌ها (شما می‌توانید جایگزین کنید)
    ├── hero.png                        ← عکس اصلی هیرو
    ├── product-spiral-classic.jpg      ← SF-01 پیچ‌دار کلاسیک
    ├── product-industrial-spiral.jpg   ← SF-02 مارپیچ صنعتی
    ├── product-cantilever.jpg          ← SF-03 کنسولی شناور
    ├── product-straight-steel.jpg      ← SF-04 مستقیم با تیر
    ├── workshop.jpg                    ← عکس کارگاه (بخش کنترل کیفیت)
    ├── project-villa-navaran.jpg       ← نمونه‌کار ویلای نیاوران
    ├── project-apartment-zafaraniyeh.jpeg ← نمونه‌کار آپارتمان زعفرانیه
    └── project-mall-kish.jpg           ← نمونه‌کار مجتمع کیش
```

## 🖼️ جایگزینی عکس‌ها با عکس‌های خودتان

برای هر عکس، **همان نام فایل را حفظ کنید** و فقط محتوای آن را عوض کنید.

### مراحل:
1. عکس خودتان را آماده کنید (پیشنهاد: JPG با کیفیت بالا، ابعاد حداقل ۸۰۰×۶۰۰ پیکسل)
2. به پوشه `assets/` بروید
3. عکس جدید را با **همان نام فایل موجود** جایگزین کنید
   - مثلاً برای ویلای نیاوران: فایل خودتان را با نام `project-villa-navaran.jpg` ذخیره کنید و روی فایل موجود کپی کنید
4. صفحه را در مرورگر رفرش کنید — عکس جدید نمایش داده می‌شود

## 🚀 اجرای سایت

### روش ۱: باز کردن مستقیم
فایل `index.html` را با هر مرورگری باز کنید. تمام کتابخانه‌ها و عکس‌ها به‌صورت محلی لود می‌شوند — **نیازی به اینترنت نیست** (به جز فونت Vazirmatn که از Google Fonts لود می‌شود، در صورت آفلاین بودن از فونت سیستم استفاده می‌شود).

### روش ۲: اجرا با لوکال سرور (پیشنهادی)
اگر روی هاست می‌گذارید، کافی است کل پوشه `spiral-stairs/` را آپلود کنید.

## ✨ ویژگی‌ها

- طراحی دارک + لوکس + اکسنت مسی
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- Bottom Navigation Bar شناور در موبایل با حالت Active خودکار
- اسکرول نرم با Lenis
- انیمیشن‌های ورود بخش‌ها با GSAP (slide از چپ/راست)
- فرم درخواست مشاوره با Toast
- بدون وابستگی به CDN — همه چیز آفلاین کار می‌کند

## 🔧 اگر خواستید رنگ‌بندی را عوض کنید

در فایل `styles.css`، در ابتدای فایل، متغیرهای `:root` را ویرایش کنید:

```css
:root {
  --bg: #0e0d0b;          /* پس‌زمینه اصلی */
  --primary: #c97a3f;     /* رنگ اکسنت مسی */
  --primary-2: #d99560;   /* روشن‌تر برای هاور */
  --fg: #f5f1ea;          /* رنگ متن اصلی */
  ...
}
```

## 📝 اگر باگی پیدا کردید

اگر انیمیشن‌ها یا منوی پایین درست کار نکرد، مطمئن شوید:
1. هر ۴ فایل در پوشه `vendor/` موجود هستند
2. فایل `scripts.js` در کنار `index.html` است
3. فایل `styles.css` در کنار `index.html` است
4. پوشه `assets/` با تمام عکس‌ها در کنار `index.html` است
